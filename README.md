# 🍽️ Projeto de Receitas

## 📌 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de praticar e aprofundar os conhecimentos em desenvolvimento front-end com React e Tailwind CSS. A proposta é oferecer uma interface agradável para visualizar receitas separadas por categorias como doces, salgadas e fit, além de dicas e banners personalizados para cada seção.

## 🎨 Tecnologias Utilizadas
- React.js → Para a construção da interface e gerenciamento de componentes

- Tailwind CSS → Para estilização rápida e responsiva

- React Router DOM → Para navegação entre as páginas

## 🚀 Como Executar o Projeto

1. Clone este repositório:
git clone https://github.com/CarolTagliaferro/SiteReceitas.git

2. Navegue até a pasta do projeto:
cd site-receitas

3. Instale as dependências:
npm install

4. Inicie o projeto:
npm start

5. Acesse no navegador:
http://localhost:3000
